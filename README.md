🔐 Gerador de Senhas

Gerador de Senhas é uma aplicação desktop moderna e elegante construída com Flet, que permite criar senhas seguras e personalizadas de forma rápida e intuitiva.

✨ Recursos
✅ Personalização completa: Escolha entre letras maiúsculas, minúsculas, números e símbolos
✅ Tamanho ajustável: De 4 a 20 caracteres com controle por slider
✅ Interface Dark Theme: Design moderno e agradável aos olhos
✅ Copiar para área de transferência: Um clique e pronto!
✅ Validação inteligente: Botão só ativa quando há pelo menos uma opção selecionada
✅ Gradientes e animações: Experiência visual fluida

🚀 Como usar
Baixe o executável ou rode o código
Selecione suas preferências (mínimo 1 opção)
Ajuste o tamanho da senha com o slider
Clique em "GERAR SENHA"
Copie com o botão 📋
